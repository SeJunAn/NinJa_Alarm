# 🥷 NinJa Alarm — BE(Room/SQLite) 작업 진행 기록

> 브랜치: `feature/room-backend`  
> 기준 브랜치: `design_temp`  
> 담당: 김동환 / BE  
> 작성일: 2026-06-11

---

## 1. 작업 목적

기존 NinJa Alarm 앱은 UI/AI 파트가 `FakeRepository` 기반으로 동작하고 있었다.  
이번 작업의 목적은 Fake 데이터 기반 구조를 실제 온디바이스 저장소인 **Room(SQLite)** 기반 구조로 교체하여, 앱 재실행 후에도 알람·술법·사용자·통계 데이터가 유지되도록 만드는 것이다.

BE 작업 범위는 다음과 같다.

- Room Entity / DAO / Database 구현
- Seed 데이터 삽입
- Entity ↔ model DTO 매핑
- `FakeRepository` → `RoomRepository` 교체
- 앱 실행 시 Repository 초기화
- 빌드 및 실행 확인

## 2. 적용한 주요 변경 사항

### 2.1 Room 의존성 추가

`gradle/libs.versions.toml`에 Room 버전을 추가하였다.

```toml
room = "2.8.4"
```

`[libraries]`에는 다음 항목을 추가하였다.

```toml
androidx-room-runtime = { group = "androidx.room", name = "room-runtime", version.ref = "room" }
androidx-room-compiler = { group = "androidx.room", name = "room-compiler", version.ref = "room" }
```

`app/build.gradle.kts`의 `dependencies`에는 다음 항목을 추가하였다.

```kotlin
implementation(libs.androidx.room.runtime)
annotationProcessor(libs.androidx.room.compiler)
```

## 6. NinjaDatabase 구현

`NinjaDatabase.java`를 추가하여 Room Database를 구성하였다.

주요 내용은 다음과 같다.

- Room `@Database` 정의
- Entity 목록 등록
- DAO 제공
- Singleton 형태의 DB 인스턴스 제공
- 최초 DB 생성 시 seed 데이터 삽입
- `exportSchema = false` 설정으로 Room schema export 경고 제거

## 10. Repositories 교체

기존 `Repositories.java`는 `FakeRepository`를 반환하던 구조였다.  
이를 Room 기반 구현체를 반환하도록 수정하였다.

추가한 내용:

```java
public static final long CURRENT_USER_ID = 1L;
```

그리고 앱 시작 시 Application Context를 보관할 수 있도록 초기화 메서드를 추가하였다.

```java
public static synchronized void init(Context context) {
    appContext = context.getApplicationContext();
}
```

Repository 반환은 다음과 같이 Room 구현체를 사용하도록 변경하였다.

```text
RoomAlarmRepository
RoomSequenceRepository
RoomDismissRepository
RoomTutorialRepository
RoomUserRepository
```

## 11. Application 클래스 추가

`NinjaAlarmApp.java`를 추가하여 앱 시작 시 Repository를 초기화하도록 하였다.

```java
public class NinjaAlarmApp extends Application {
    @Override
    public void onCreate() {
        super.onCreate();
        Repositories.init(this);
    }
}
```

`AndroidManifest.xml`의 `<application>` 태그에는 다음 속성을 추가하였다.

```xml
android:name=".NinjaAlarmApp"
```

## 13. 현재 동작 확인 결과

앱 실행 확인 결과:

- 앱 정상 실행
- 로그인 화면 진입 가능
- 로그인 후 홈 화면 진입 가능
- Room 기반 데이터 로딩 가능
- 빌드 성공

단, 현재 로그인 기능은 실제 인증과 연결되어 있지 않다.  
따라서 로그인 화면에서 아무 값을 입력해도 홈으로 진입하는 것은 현재 단계에서는 정상이다.

회원가입 버튼도 아직 실제 회원가입 화면/인증 로직과 연결되지 않은 상태이다.
