## 1. 작업 개요

이번 작업에서 다음 3가지를 처리했다.

1. **로그아웃 버튼 추가** — 프로필 화면에서 로그아웃. 단, **Room DB 캐시는 보존**(세션만 삭제).
2. **인 학습 튜토리얼 상세(맺는 법) 화면** — 12간지 인(印)을 맺는 방법을 손모양 그림 + 설명으로 보여주는 캐러셀.
3. **수인(手印) 손모양 이미지 적용 + 최적화** — 도식형 벡터로 시작 → 실제 일러스트 12종으로 교체 → 용량 최적화.

모든 변경은 빌드(`assembleDebug`) 통과 및 에뮬레이터(Pixel_10_Pro) 실기기 확인을 마쳤다.

## 2. 로그아웃 버튼 추가

### 2.1 요구사항
- 프로필 화면에 로그아웃 버튼 생성.
- **로그아웃 시 Room DB 캐시(알람·시퀀스 등)를 지우지 않을 것.**

### 2.2 구현
- 기존 `Session.clear(Context)` 가 이미 SharedPreferences의 `current_user_id` 키 **하나만 제거**하고
  Room DB는 건드리지 않음을 확인 → 그대로 활용.
- 코드베이스 전체에 `clearAllTables()`·DB 삭제 호출이 **없음**을 확인.

```java
private void logout() {
    // 세션(SharedPreferences)만 비운다. Room DB 캐시(알람·시퀀스 등)는 의도적으로 보존한다.
    Session.clear(requireContext());
    Intent intent = new Intent(requireContext(), LoginActivity.class);
    startActivity(intent);
    requireActivity().finishAffinity(); // 백스택을 비워 뒤로가기로 홈 복귀 차단.
}
```

### 2.3 동작
프로필 하단 **로그아웃** 버튼(OutlinedButton) → 확인 다이얼로그("…기기에 저장된 데이터는 그대로 유지됩니다.")
→ 확인 시 세션만 삭제하고 `LoginActivity` 로 이동. 취소 시 무동작.

### 2.4 변경 파일
- `ui/profile/ProfileFragment.java` — 버튼 핸들러 + 확인 다이얼로그 + `logout()`
- `res/layout/fragment_profile.xml` — 로그아웃 버튼 추가
- `res/values/strings.xml` — `profile_logout`, 확인 다이얼로그 문자열

## 3. 인 학습 튜토리얼 상세(맺는 법) 화면

### 3.1 배경
기존 `TutorialActivity` 는 12간지 인의 한자·이름·완료 체크만 보여줄 뿐, **맺는 방법을 알려주는 시각 자료가 없었다.**
인은 코드상 **십이지 12개**로 시드돼 있고(ML 모델도 12개만 시퀀스 매칭에 사용), 이를 기준으로 했다.

### 3.2 구현 — 리스트 + 상세(캐러셀)
- 기존 목록은 유지하되, **카드 탭 → 상세 화면**으로 진입하도록 연결.
- 상세는 `ViewPager2` 캐러셀: 좌우 스와이프로 인을 넘기며 **큰 손모양 그림 + 이름 + "맺는 법" 설명** 표시.
- 상단에 `n / 12` 위치 텍스트 + 진행 바.
- 목록과 상세가 **동일 출처·순서**(`Repositories.sequence().getSeals()`)를 사용해 위치(index)가 일치.
- "맺는 법" 설명은 데이터 계층(Room/SealEntity)을 건드리지 않고 **문자열 리소스 배열**(`seal_howto`, 12개)로 관리.

## 4. 수인 손모양 이미지

### 4.1 진행 경과
1. **도식형 벡터(초기)** — 사실적 손 이미지 생성 수단이 없어, 두 손·손가락을 단순화한
   `VectorDrawable` 12종(`seal_01~12.xml`)을 우선 제작해 자리표시자로 사용.
2. **실제 일러스트로 교체(최종)** — 12간지 동물 이름의 실제 수인 일러스트 PNG 12종을
   `res/drawable` 에 추가받아 적용. 도식 벡터는 제거.

### 4.2 매핑 (sealId 1~12 = 십이지 순서)
`rat, ox, tiger, hare, dragon, snake, horse, ram, moneky, bird, dog, boar`
→ `SealPagerAdapter.SEAL_ART` 배열로 sealId에 매핑.
※ 원숭이 파일명이 `moneky`(오타)이나 리소스명으로 유효해 그대로 참조(동작 정상).

### 4.3 표시 처리
- 일러스트가 **흰 배경**이라, 상세 화면의 그림 영역을 어두운 원형 자리표시자 →
  **흰 라운드 카드 + 오렌지 테두리**(`MaterialCardView`, cornerRadius 20dp) 프레임으로 변경.
- 표시 우선순위(어댑터): **외부 `imageUri` > 번들 이미지(`SEAL_ART`) > 한자 폴백.**

### 4.4 이미지 최적화
원본은 각 **2104×2048, 3~5MB**(총 50.6MB)로, 표시 크기(약 840px) 대비 과대 → APK 134MB.

- 원본을 `art_src/seals_original/` 에 **백업**.
- `1024px` 리사이즈 + **JPEG q90** 재인코딩(불투명 흰 배경이라 JPEG 적합).
- 파일명은 그대로 두고 확장자만 `.jpg` → `R.drawable.*` 참조 무관, **코드 수정 불필요**.

| 항목 | 이전 | 이후 |
|---|---|---|
| 이미지 12개 합계 | 50.6 MB | **0.86 MB** |
| 디버그 APK | 134.4 MB | **83.8 MB** |

화면 표시 품질 차이 없음, 메모리·OOM 위험 동반 감소.

### 4.5 변경 파일
- `res/drawable/{rat,ox,tiger,hare,dragon,snake,horse,ram,moneky,bird,dog,boar}.jpg` (신규/최적화)
- `ui/tutorial/SealPagerAdapter.java` — `SEAL_ART` 매핑
- `res/layout/item_seal_page.xml` — 흰 카드 프레임
- 제거: `res/drawable/seal_01~12.xml`(도식 벡터), `bg_seal_placeholder.xml`
- 백업: `art_src/seals_original/*.png`(원본 12종)
- 참고: `docs/seal_images_guide.md` (AI 생성/교체 가이드 — 벡터 기준이라 일부 낡음, 갱신 예정)
